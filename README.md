# 字幕侧栏 Subtitle Sidebar

Chrome / Edge 扩展：在 YouTube 和 B站视频右侧显示字幕浮窗，随播放自动滚动、点哪句跳哪句、可全文搜索，支持双语对照。

当前进度：**M3（导入、摘要、笔记、复制提示词）**。AI 一键生成、遮挡模式、卡密激活见 M4；免费 / 付费的划分也在 M4 统一实现。

## 安装（开发版）

```bash
npm install
npm run build
```

然后在 Chrome 打开 `chrome://extensions`（Edge 为 `edge://extensions`），打开右上角「开发者模式」，点「加载已解压的扩展程序」，选择 `dist/` 目录。改代码后重新 `npm run build`，再在扩展页点刷新按钮即可。

## 功能

- 自动读取视频自带字幕：人工字幕优先，没有就用自动字幕；去掉字幕里的 HTML 格式标记（如 `<b>`）
- 双语：有人工中文轨道就用；没有就尝试 YouTube 机翻中文（可能被限流，失败时只显示原文）
- 合句：带标点的按句子合并；无标点的自动字幕按停顿断句，单句约 22 词以内
- 随播放高亮并滚动；手动滚动后暂停跟随，点「回到当前」恢复
- 点击任意一句，视频跳到该处
- 搜索：高亮所有结果，Enter / Shift+Enter 切换
- 双语 / 仅原文 / 仅译文切换，字号调节，拖动左边缘调宽度，可收起
- 跟随网站深色模式，全屏时自动隐藏
- 单句循环：播到句尾跳回句首；循环中点别的句子就改循环那一句
- 快捷键：`[` 上一句，`]` 下一句，`\` 开关单句循环（在输入框里打字时不响应）

### 摘要、笔记（M3）

浮窗分三个标签：字幕 / 摘要 / 笔记。右上角 ⋯ 菜单里依次是：

- **复制 AI 提示词**：把字幕和生成规则（与 bilingual-srt-translator skill 一致）复制到剪贴板，粘贴到任意 AI。已有中文字幕（原文是中文，或已有中文译文，包括 YouTube 机翻）时只让 AI 生成摘要；没有中文字幕时让 AI 生成中英双语 SRT 和摘要
- **文件命名**：提示词里写明 AI 要返回的文件名，就是复制提示词时的日期时间连写（年月日时分），如 `202610182322.json`，双语字幕为 `202610182322.srt`。扩展会记下每个文件名对应哪个视频
- **导入**：选择 AI 返回的文件；为别的视频生成的文件会被拦下。AI 没生成文件、直接回复文字时，也可以把回复粘贴进来，会从代码块里识别双语 SRT 和摘要 JSON（分几次回复的 SRT 会拼起来）
- **恢复为网站字幕**：导入的字幕会代替网站字幕，可随时切回

- 摘要：按话题分段，当前话题高亮，点击跳到话题开头；点右侧 ☆ 收藏到笔记
- 笔记：在字幕或摘要里点右侧的 ☆ 收藏；可切换「想法 / 好句」、写批注；导出 Markdown，每条带回到视频该处的时间戳链接（摘要笔记带加粗标题）
- 导入的双语 SRT 若是按原始行切分的（skill 的产物就是），会把跨行的句子合并，原文译文一起合
- 导入的内容和笔记按视频保存在扩展自己的存储里（`chrome.storage.local`，清除网站数据不会丢）；离开页面时立即保存未存的修改
- 想自己翻译时，「复制 AI 提示词」里已带完整的原文字幕

### B站

- 支持分P（`?p=`），站内切换分P或换视频都会更新
- 字幕优先用拦截到的播放器接口数据，拿不到再自己请求
- B站只向登录用户提供字幕；未登录时浮窗会提示登录
- 接口偶尔返回别的视频的字幕：按字幕时长和视频时长比对，对不上就重新请求
- 英文搬运视频常见「AI 英文 + AI 中文」两条轨道，会自动配成双语；B站没有机翻，没有第二条轨道时只显示原文

## 字幕是怎么拿到的

**YouTube**：现在要求字幕请求带 PO Token，轨道列表里的 `baseUrl` 直接请求会返回空内容。扩展按顺序尝试：

1. 直接请求 `baseUrl`
2. **拦截播放器自己发出的 `/api/timedtext` 请求**，把其中的 PO Token 等参数补到目标轨道地址上（主力；用户没开字幕时会临时点开一次 CC 再恢复）
3. 打开「内容转文字」面板，从页面读取

详见 `src/sites/youtube.ts`。

**B站**：读页面 `__INITIAL_STATE__` 拿到分P的 cid；拦截播放器请求的 `/x/player/wbi/v2` 响应得到字幕列表（省去 WBI 签名），没拦截到就自己带 cookie 请求。详见 `src/sites/bilibili.ts`。

网站改版时只需要改 `src/sites/` 下的文件。

## 目录

```text
src/
  sites/        站点适配器（youtube.ts、bilibili.ts，以及各自的轨道选择 *-tracks.ts）
  inject/       主世界脚本：拦截字幕请求、读取播放器数据
  content/      内容脚本入口、与主世界通信、播放同步
  core/         与网站无关的纯逻辑：json3 解析、合句、中英配对、时间格式、
                SRT 读写、摘要校验、导入识别、AI 提示词、笔记 Markdown
  ui/           浮窗（Preact，渲染在 Shadow DOM 里）
  storage.ts    设置与每个视频的数据（导入内容、笔记）
static/         manifest.json
tests/          单元测试；harness/ 是端到端测试
```

## 测试

```bash
npm test            # 单元测试
npm run typecheck   # 类型检查
npm run e2e         # 端到端测试（需要本机安装 Chrome）
```

端到端测试用两个模拟页，在无头 Chrome 里检查浮窗行为：

- `tests/harness/harness.html`：模拟 YouTube 播放器和字幕接口（包括「无 PO Token 返回空」「机翻 429」）
- `tests/harness/harness-bili.html`：模拟 B站（两个分P、未登录、返回错误字幕、页面状态过期）

首次运行前准备测试数据：

```bash
python3 tests/harness/prepare-data.py a_bilingual.srt [b_bilingual.srt]
```
